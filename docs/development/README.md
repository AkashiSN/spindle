# 開発の作業記録

開発中の作業用の文書を置く場所。利用者向けの文書ではない。

## 新しい機能を作るとき

1. 設計書（`YYYY-MM-DD-<topic>-design.md`）と実装計画（`YYYY-MM-DD-<topic>.md`）は、作業中だけこのディレクトリに置く
2. 実装が済んだら、要点を [仕様](../spec/README.md) の該当する章へ、判断とその理由を
   [設計判断の記録](../decisions/README.md) へ移す
3. 移し終えたら設計書と計画をこのディレクトリから消し、同じ PR に含める

設計書や計画をリポジトリに残し続けると、仕様と食い違ったまま古くなる。正は仕様と設計判断の記録だけにする。
