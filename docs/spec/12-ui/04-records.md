# 12.4 記録（編集履歴 / 退避ファイル / ログ）

☰ の「記録」（旧「履歴」）は 3 つのタブを持つ: **編集履歴 / 退避ファイル / ログ**。設定にあった退避ファイルと、
操作タブが実ファイルのパスで案内していた照合ログをここに集める（[D-106](../../decisions/D-106.md)）。

- **退避ファイル**: `archived_files` の一覧と復元。既定は保持中（`held`）で 100 件ずつ（「もっと見る」で
  `cursor`）。状態ごとの件数は `counts`。GC で実体を消した記録（`deleted`）は既定では出さない。
  上部の切り替えは 保持中 n / 復元済み n / 削除済み n / すべて。保持中が 0 件なら「保持中の退避ファイルは無い
  （削除済み n 件は GC で実体を消した記録）」。列と「バッチ #n を巻き戻す」は設定画面にあったときと同じ
- **ログ**: 照合（`retro`）と吸い出し（`rip`）の実行ごとの一覧（50 件ずつ。`kind` で絞る）。照合ログは
  album ごとに最新 1 回分しか残らないので、古い実行は `superseded`（「上書きされた」）と出す。吸い出しログは
  DB の `log_path` を使わず、その disc の active な曲がいまあるディレクトリから `rip.log` / `rip<N>.log` を引く
  （リネームに追随する）。行を開くと本文を読み、コピーとダウンロードができる。Inbox の承認画面でも CD の
  取り込みの `rip*.log` / `cue` / `toc` を読める（`GET /api/inbox/:id/files/:name`）
  - 一覧の行は日時・種別（照合 / 吸い出し）・album・結果の要約（手法 × ディスクを並べた 1 行。複数枚組は
    `disc 1: CTDB 一致 / AR 一致 · disc 2: …`）。本文は等幅・折り返さず横スクロール。ページ送りは offset なので、
    間に新しい実行が増えて重なった行は `key` で捨てる
  - 本文が無いときの文言: `superseded` は「このログは後の照合で上書きされた」、404 は「ログが残っていない
    （後の照合で上書きされたか、ファイルが無い）」（Inbox では「ファイルが見つからない（Inbox から移動・削除された）」）、
    413 は「ログが大きすぎて表示できない（1 MiB 超）」
  - **入口**: 操作タブの照合結果（④）の各行の「ログ」、プロパティの「照合・吸い出しのログを見る」（選択が 1 つの
    album のときだけ）、ジョブ画面の verify の行を開いたときの「ログを見る」（`payload.album_id`）。どれも
    記録 > ログをその album で絞って開く。rip のジョブ行には出さない（Inbox に置くまでで album を知らない。
    承認前の吸い出しログは Inbox で読む）。操作タブはログを実ファイルのパスで案内しない
- **タブの切り替え**: 画面の状態で持ち、他画面からは `openRecords({ tab, … })` で開く（ジョブ画面と退避ファイルの
  「バッチ #n」は編集履歴タブでそのバッチを開く）
- **編集履歴タブ**: 以下

```
#42  09-16 14:03  "Official を除去"      tags    1,204 件   applied              [巻き戻す]
#41  09-16 13:50  "アーティスト統一"      tags      312 件   partial (conflict 3)  [巻き戻す] [conflict を見る]
#40  09-16 13:20  "リネーム J-Pop/…"     rename    980 件   applying 640/980      [キャンセル]
#39  09-15 …       (#38 の巻き戻し)      tags       50 件   applied   ↩ #38       [巻き戻す(=やり直し)]
#38  09-15 …       "…"                   tags       50 件   applied   reverted     —
```

- 行を開くと op 一覧（トラック / result / error）。conflict の op は「ファイルを再読込した」旨と
  現在値を表示
- [巻き戻す] は終端状態のみ有効。`reverted_at` 済みは無効化して「#39 で戻し済み」と表示
- 巻き戻しも新バッチなので同じ一覧に現れる（`reverts_batch_id` を ↩ で表示）
- [キャンセル] は `prepared` / `applying` のみ
