# D-93 表の画像だけを同じリリースグループの別の版から取れるようにする

**決定**（2026-09-25。P4-23。ユーザの要望: 「MusicBrainz の候補に出ている別のリリース（BD 版や初回限定版）には
カバー画像があるが、取り込みたい通常盤には登録されていないとき、メタデータは通常盤のまま、カバー画像だけ別の
リリースにしたい」。自動の補完と手動の選択の両方を入れる案をユーザが選んだ）:

- **自動（[D-91](D-091.md) の拡張）**: 承認前の CD の取り込みで、吸い出したリリースの front が 404 なら、サイドカーの
  `rip.metadata.release_group_id` があるとき**同じ回の中で**リリースグループの front
  （`release-group/{id}/front-500`。CAA がグループの代表に選んだ版の表の画像）を 1 度だけ試す
  （`import::cover::fetch_front`、`CoverArtClient::group_front`）。claim した 1 回の中の試行なので回数は増やさない。
  グループの 404 はリリースの 404 と同じく打ち止め、グループの上流の失敗はリリースの失敗と同じく次の走査で
  もう 1 回だけ。リリースに画像があればグループは引かない。どちらから取ったかはログ（`source`）にだけ残し、
  DB には持たない（`caa_picture` は置いた画像の値で、画面の「画像を外す」の判定にしか使わない。
  出どころを持つにはマイグレーションが要り、見返りが無い）。画面の文言は「吸い出したリリースかそのリリース
  グループから自動で取った」にする
- **手動**: Inbox の承認画面の画像の欄に「別のリリースから取る…」（`CaaReleasePicker`。曲ごとに画像が違う
  取り込みには出さない）。メタデータは取り込むリリースのまま、画像だけを置いて全曲の `picture` に入れる
  （従来の `applyPicture(…, 'all')`。配置で埋め込む）
  - 下書きの `release_group_id` があれば、同じグループの版を `GET /api/cd/release-group/{id}/releases`
    （MusicBrainz の browse `ws/2/release?release-group=…&inc=media+labels&limit=100`。既存の
    `MusicBrainzClient` の 1 req/s に乗る）で並べる。MusicBrainz のリリースは `cover-art-archive.front` を
    持つので、表の画像のある版だけをジャケット（`/api/cd/cover/{id}` の中継）付きで出し、無い版は件数だけ。
    並びは front のある版が先、同じなら日付の古い順。見分けに日付・国・形式（`CD + Blu-ray` 等）・レーベル・
    カタログ番号を出し、取り込むリリースに印を付ける。グループが 100 件を超えるときは先頭のぶんだけ
  - 「リリースグループの代表画像を取る」（`from-caa { release_group_id }`）
  - 別のグループに登録された版（BD 版が別のリリースグループになっている等）のために、MusicBrainz のリリースの
    URL か MBID の貼り付け。`from-caa { release_id }` はサーバで `parse_release_ref` を通すので URL も受ける
- `POST /api/artwork/from-caa` は `{ release_id }` か `{ release_group_id }` のどちらか片方（両方・無しは 400）

**理由**: 実機の嵐「Five」のリリースグループは CD + Blu-ray（画像あり）・CD + DVD-Video（画像なし）・配信
（画像なし）の 3 版で、DVD 付きを吸い出すと [D-91](D-091.md) は画像なしで終わる。表の画像は版が違ってもほぼ同じで、
CAA もグループの代表画像を持っている。自動の補完で多くは埋まり、違う版の画像にしたいときだけ一覧から選ぶ。
これまでの回避策（別の版の画像をブラウザで保存してドロップする）は MusicBrainz を別に開く必要があった。

**却下**: 取り込むリリースをグループ内の画像のある版へ変える（メタデータ = カタログ番号・媒体構成・
`MUSICBRAINZ_ALBUMID` が実物の盤と食い違う）。手動を URL / MBID の貼り付けだけにする（変更は小さいが、別の版の
MBID を MusicBrainz で探して貼る手間が残る。ユーザの選択で一覧を付けた）。グループの版の一覧をキャッシュする
（開くのは件ごとに 1 回程度で、MusicBrainz の間隔制御に乗っていれば足りる）。
