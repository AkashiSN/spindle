# 設計判断の記録

実装中に「なぜこうなっているのか」を調べ直さなくて済むように、
判断とその理由、および却下した案を残す。
**ここに記録された判断を実装時に覆さないこと。** 覆すべき理由が見つかった場合は
実装を止めて確認する。
